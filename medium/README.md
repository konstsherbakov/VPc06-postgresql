# Средний уровень — связи, JOIN и SUM в PostgreSQL

Программа создаёт таблицы `users` и `orders`, добавляет пользователей и заказы из кода, проверяет `ON DELETE CASCADE` и печатает сумму заказов по каждому пользователю.

## Файлы

- `postgres_driver.py` — класс `PostgresDriver`: соединение и методы `create_tables`, `add_user`, `add_order`, `delete_user`, `get_user_totals`.
- `main.py` — пример использования класса.

## Что реализовано

- **Связь:** `orders.user_id → users.id` с `ON DELETE CASCADE` — при удалении пользователя удаляются и его заказы.
- **Параметризованные запросы:** все значения передаются через `%s`, а не вклеиваются в текст SQL — защита от SQL-инъекций.
- **Транзакции:** каждая операция выполняется в `with conn:` — при ошибке изменения откатываются.
- **Агрегация:** `LEFT JOIN + SUM + GROUP BY`, пользователи без заказов попадают в отчёт с суммой 0.00, сортировка по сумме по убыванию.
- **Ошибки:** перехватывается `psycopg2.Error`, соединение закрывается в `finally`.
- **Повторный запуск:** демо-пользователи добавляются только один раз, дубликатов нет.

## Запуск (Windows, PowerShell)

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

В файле `.env` указать свой пароль в `DB_PASSWORD`, затем:

```
python main.py
```

Таблицы создаются автоматически. Если появится `permission denied` для схемы `public`, выдайте пользователю права на схему в pgAdmin.

  Глеб  —    999.99  (заказов: 3)
  Вера  —      0.00  (заказов: 0)
